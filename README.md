# 1 из 146 миллионов

Текстовый симулятор жизни в России, полностью offline. Ты выбираешь пол, имя, фамилию и год рождения (1985–2035). Регион, семья, деньги, здоровье, задатки разыгрываются по статистическим данным и помеченным модельным приближениям. Дальше — жизнь по месяцам, решения и вероятности.

**Статус: этап 11.** Вся жизнь от рождения до смерти в 85 субъектах РФ: детство, школа и ЕГЭ, вуз/колледж, армия, карьера, бизнес, деньги, ипотека, своя семья, болезни взрослых, ОМС/ДМС, пенсия, старость, полиция, суды, коррупция. Поверх — то, что делает жизнь тяжёлой и русской:

- **характер** меняет мир (увольнения, разводы, исходы выборов, поступки по характеру);
- **связи** — конкретные люди и долги перед ними: помог тебе — попросит в ответ; откажешь — наживёшь врага;
- **решения аукаются через годы** (купленная курсовая, «левый» акт, измена, родители, дети, «конверт» и пенсия);
- **тяжёлые 30–60:** кредитная кабала, ипотека и торги, выгорание, остывший брак, одиночество, медицина с квотами;
- **женская линия:** «мы возьмём мужчину», декрет, «вторая смена», алименты, безопасность, ЭКО и «часики»;
- **регион как судьба:** клановость, лифты, профессии по типу поселения, «уехать или остаться», контракт как лифт;
- **эмиграция:** страны с разной адаптацией, непризнанные дипломы, пара и дети, возвращение с потерями;
- **итоговый отчёт** — социологический разбор: ты против медианы своей когорты, «что было бы, если», тихие отметки.

## Запуск

Двойной клик по **`Играть.exe`** (открывает игру в браузере) или по `index.html`. Сервер и интернет не нужны.

## Управление

- ▶/⏸ — пауза; x1–x16 — ускорение; «сек/год» — длительность года (5–40 с).
- «авто» — игра решает сама (с учётом уже сложившегося характера).
- «Сохранить» — в браузер (localStorage); «Экспорт» — в JSON-файл; загрузка — на стартовом экране.
- Автосохранение — на каждый день рождения.

## Проверка симуляции

```bash
node tests/sim-check.js 1020
node tests/young-check.js
node tests/ticket-check.cjs
node tests/stats-check.js
node tests/life-check.js
node tests/depth-check.js 250
node tests/fuzz-check.js 150
node tests/kin-check.js
node tests/events-lint.js
```

`life-check` — смертность по возрастам против таблиц Росстата; `depth-check` — частоты взрослых систем (эмиграция, кабала, банкротство, связи, цепочки, влияние характера, причины смерти, онкология, доход к медиане); `fuzz-check` — исключения, мусор в текстах, род, анахронизмы; `kin-check` — упоминания умерших родственников; `events-lint` — неизвестные факты и эффекты в событиях.

Прогоняет указанное число жизней (годы рождения 1985–2035) до 25-летия или смерти. Печатает распределения стартовых условий, смертность, подростковые экзамены и траектории, поступление и формы обучения, дипломы, службу, занятость, отдельное проживание и зарплаты. Для более устойчивой оценки используйте 2040 и более жизней. Методика, цели и результаты калибровки — в [docs/DATA.md](docs/DATA.md); цели модели не равны подтверждённой официальной статистике.

## Как добавить событие

Добавь объект в любой `js/data/events_*.js` (или новый файл, подключённый в `index.html` до `fixes.js`) по схеме [event.schema.json](docs/schemas/event.schema.json). Код менять не нужно. Список доступных фактов для условий — функция `RL.S.facts` в `js/sim/state.js` (и `facts` модулей). Отложенное последствие — эффект `later: {id, years: [a, b], p}`. Проверка — `node tests/events-lint.js`.
