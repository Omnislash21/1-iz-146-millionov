# Проверка этапа 2 — 26 октября 2026

## Команды

Из корня проекта:

```bash
node tests/young-check.js
node tests/ticket-check.cjs
node tests/stats-check.js
node tests/sim-check.js 1020 --json tests/calibration-1020.json
node tests/sim-check.js 3060 --json tests/calibration-3060.json
node tests/sim-check.js 2040 --birth-year 1985 --json tests/calibration-1985.json
```

Численные результаты и определения знаменателей — в [DATA.md](DATA.md), полный вывод — в `calibration-*.txt`. Выборка 1020 входит в выборку 3060; суммировать их как независимые наблюдения нельзя. Когорта рождения 1985 проверяет молодость в 2003–2010 годах. В JSON сохраняются SHA-256 исходников и тестового скрипта, чтобы результат можно было связать с конкретной версией кода.

## Браузер

Проверено в установленном Chrome через Playwright непосредственно по `file:///…/index.html`, без сервера. Использовались кнопки интерфейса и виртуальные часы для ускорения таймеров; авто- и ручная жизни прошли все месяцы от рождения до 25-летия. В ручном режиме решения принимал тестовый сценарий через кнопки, флажок «авто» был выключен.

- Полная авто-жизнь: женщина, 2003, seed 1001, завершение в 25.
- Полная ручная жизнь: тот же старт, путь СПО → вуз → диплом, завершение в 25.
- Первая приёмная кампания после 11 класса: seed 1008, 17 лет 10 месяцев, выбор направления, бюджет/платное/заочное, зачисление и отображение общежития.
- Повестка: мужчина, 1985, seed 2, естественное решение симуляции в 18 лет 8 месяцев; импорт JSON, выбор «Пойти служить», первый месяц службы, сохранение в localStorage.
- Проверен JSON Blob, сформированный обработчиком «Сохранить историю». Работа системного менеджера загрузок не входит в эту проверку.
- Ошибки страницы JavaScript: 0. Внешние HTTP(S)-запросы игры: 0.

## Границы проверки

JSON-схемы проверены на корректный JSON и внутренние ссылки; полноценная валидация сохранений по стандарту JSON Schema отдельно не выполнялась. Импорт игры не применяет эти схемы. Общежитие колледжа остаётся частью семейного бюджета. Целевая отработка, точные правовые условия отсрочек и жизнь после 25 лет не добавлялись. Приём 1990-х не покрывается текущим диапазоном годов рождения: для таких вступительных кампаний нет когорты, а не нулевой процент поступлений.
